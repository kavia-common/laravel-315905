Static-only preview

This folder is served by the VS Code Five Server extension and intentionally contains no PHP/Blade.

What is this?

Use /static for quick prototypes, HTML/CSS experiments, and static asset previews without running Laravel.

  • No PHP execution
  • No Blade rendering
  • Ideal for static mockups and quick UI iterations

Need the real Laravel app?

Start Laravel separately (example): 

PORT=3001 composer run start

Then open the Laravel app at: http://localhost:3001

Served by Five Server at http://localhost:5500
